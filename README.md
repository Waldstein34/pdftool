# PDFツール

ブラウザで動く PDF ビュワーです。インストール不要で、URL を開くだけで使えます。

- **読む**：ページ一覧・目次・拡大縮小・PDF の中の検索・文字のコピー
- **書き込む**：ペン（筆圧対応）・マーカー・消しゴム・投げ縄・図形・線・矢印・付箋・テキスト・アイコン
- **書き込みごと保存**：書き込みを重ねた PDF を「元の名前（書き込み済み）.pdf」として保存（元の PDF はそのまま）
- **書き込みは自動で保存**：同じ PDF を開き直すと、書き込みが戻ります（名前を変えても戻ります）
- **PDF はどこにも送りません**：読み込み・書き込み・保存は、すべてあなたのパソコンの中で行います

## アプリとして使う（Chrome・Edge）

アドレスバーの「インストール」ボタンを押すと、普通のアプリのように使えます。
インストールすると、PDF を右クリック →「プログラムから開く」でこのツールを選べます。

## 動作環境

- Chrome・Edge（おすすめ）：すべての機能が使えます
- Firefox・Safari：読む・書き込むは使えます。保存は「ダウンロード」になり、最近開いた PDF は選び直しが必要です
